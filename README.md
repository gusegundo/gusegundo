### [Study Flashcards](https://github.com/gusegundo/study-flashcards)

App full-stack para criar e revisar flashcards de qualquer assunto, construído em torno de um baralho de cartas que você **vira com um clique** e **passa arrastando**.

- **Baralho interativo:** layout de três cartas, animação de virar em 3D e gestos de arrastar (direita para a próxima, esquerda para a anterior), com navegação circular. Feito com Pointer Events e CSS, sem biblioteca de animação.
- **Front end em React:** React 19, Vite e Tailwind CSS. Responsivo, com navegação por teclado e respeito à preferência de movimento reduzido.
- **Back end em FastAPI:** API REST com CRUD completo, categorias e documentação interativa automática (Swagger).
- **Também inclui** uma versão do app para o terminal, com persistência em SQLite.
